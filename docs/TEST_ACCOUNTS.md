## Mock 数据说明

### 数据持久化

本项目使用 MSW (Mock Service Worker) + localStorage 实现数据持久化：

- **用户数据**: 保存在 `localStorage` 的 `campus_food_users` 键
- **订单数据**: 保存在 `localStorage` 的 `campus_food_orders` 键
- **菜品数据**: 保存在 `localStorage` 的 `campus_food_dishes` 键
- **食堂数据**: 保存在 `localStorage` 的 `campus_food_canteens` 键
- **分类数据**: 保存在 `localStorage` 的 `campus_food_categories` 键
- **地址数据**: 保存在 `localStorage` 的 `campus_food_addresses` 键
- **购物车数据**: 保存在 `localStorage` 的 `campus_food_carts` 键
- **管理员数据**: 保存在 `localStorage` 的 `campus_food_admins` 键

### 数据重置

如需重置 Mock 数据到初始状态：

```javascript
// 在浏览器控制台执行
localStorage.clear()
location.reload()
```

或者清除特定数据：

```javascript
// 清除用户数据
localStorage.removeItem('campus_food_users')

// 清除订单数据
localStorage.removeItem('campus_food_orders')

// 以此类推...
```

### 数据共享

用户端和管理端共享同一份 Mock 数据（通过 `@campus-food/shared` 包），因此：

- 在管理端修改的数据，用户端可以立即看到
- 在用户端创建的订单，管理端可以管理
- 两端数据完全同步

## 注意事项

1. **数据是临时的**: Mock 数据存储在浏览器 localStorage，清除浏览器缓存会导致数据丢失
2. **跨浏览器不共享**: 不同浏览器的数据是独立的
3. **开发专用**: 测试账号仅用于开发和测试，生产环境需要真实后端 API
4. **密码安全**: 测试环境的密码都是简单密码，生产环境需要使用强密码
